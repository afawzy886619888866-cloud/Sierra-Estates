───────────────────────────────────────────────────────────────────
١) إجابة السؤال: نضيف ولا نبدّل ولا نمسح؟
───────────────────────────────────────────────────────────────────
الإجابة: ندمج — ومتمسح ولا حاجة.

الشيت بتاعكم عليه App Script محرك كامل (v5.5) شغال وبيأدي حاجات
كتير — لو مسحته هتضيع:
  ✗ بوت الواتساب (إضافة الوحدات من الجروبات) — Mode B
  ✗ تحديث «تاريخ اخر تواصل» أوتوماتيك — Mode A
  ✗ المنيو والأوديت (توحيد الكومباوندات + سقف الإيجار ٤٠٠ ألف
    + تنسيق الموبايلات + منع الفراغات)
  ✗ onEdit (التنسيق والتواريخ الأوتوماتيكية أثناء الشغل)
  ✗ ولو نشرت Deployment جديد → اللينك بيتغير والبوت القديم بيوقف

عشان كده اتعمل ملف واحد «مدموج» = كودك القديم كامل زي ما هو
(سطر بسطر) + إضافة Easy Listing في الآخر (Mode C). مفيش أي حاجة
من القديم اتشالت أو اتغيرت.

───────────────────────────────────────────────────────────────────
٢) خطوات الربط (٣ دقايق — من حساب الجوجل صاحب الشيت)
───────────────────────────────────────────────────────────────────
الخطوة ١: افتح الشيت (اللينك فوق) ← من القائمة: Extensions ← Apps Script
          (هتلاقي جوه كود المحرك القديم — سيبه زي ما هو)

الخطوة ٢: انسخ الكود المدموج كله (من القسم ٣ تحت، أو من ملف
          apps-script-easy-listing.gs المرفق، أو من زرار «نسخ الكود»
          في دليل الربط جوه الصفحة) ← اعمل Ctrl+A في محرر الكود
          ← الصق ← احفظ (Ctrl+S)

الخطوة ٣: Deploy ← Manage deployments ← ✏️ (قلم التعديل) ←
          Version: New version ← Deploy
          — كده اللينك القديم هيفضل هو هو والبوت مش هيتقطع.
          (لو أول مرة تنشر: Deploy ← New deployment ← Web app مع
           Execute as: Me و Who has access: Anyone)

الخطوة ٤: انسخ الـ Web app URL (شكله كده):
          https://script.google.com/macros/s/AKfy.../exec

الخطوة ٥: افتح https://sierra-easy-listing.vercel.app ← زرار
          «الإعدادات» والصق:
            - لينك الـ Apps Script (اللي نسخته)
            (كلمة السر Secret متضبطة جاهزة — متغيرهاش)
            - رقم واتساب الشركة (يتحط تلقائيًا جوه كل محتوى)
          واضغط «حفظ» وبعدها «اختبر الاتصال» — لازم يظهرلك «متصل ✅»

من دلوقتي: كل «احفظ الوحدة» = صف جديد في تاب Listings في الشيت
+ الصور بتترفع على مجلد «Easy Listing Images» في Google Drive
و روابطها بتتكتب في عمود Images (URLs).
وللبوت القديم: شغال زي ما هو بنفس اللينك ونفس السر.

═══════════════════════════════════════════════════════════════════
٣) الكود المدموج (v6.0)
═══════════════════════════════════════════════════════════════════
الكود كامل في ملف apps-script-easy-listing.gs المرفق (٩٤٦ سطر)،
ونفس الكود موجود جوه الصفحة في «دليل الربط» بزرار نسخ.

ترتيبه:
  - الأقسام ٠–٥: محرككم القديم v5.5 زي ما هو بالظبط
    (doGet / doPost بـ Mode A و Mode B / onOpen / onEdit /
     دوال الأوديت المساعدة)
  - القسم ٦ (جديد): Easy Listing — دالة handleEasyListing_ +
    تاب Listings (١٥ عمود) + رفع الصور على Drive
  - الإضافة جوه doPost: سطر واحد بيفحص mode = "easy_listing"
    وبيوجه الطلب للدالة الجديدة قبل Mode A/B
  - الإضافة جوه onOpen: عنصر منيو واحد «📄 Prepare Listings
    Sheet» (اختياري — بيعمل تاب Listings مسبقًا)

───────────────────────────────────────────────────────────────────
٤) ملاحظات مهمة
───────────────────────────────────────────────────────────────────
- مفيش أي API Keys جديدة ولا تكاليف — الحل كله على الطبقة
  المجانية من Google + Vercel.
- كلمة السر (Secret): نفس سركم القديم SE_OUTREACH_SECRET_2026_CAIRO
  — الصفحة بتبعتها مع كل حفظ، والسكريبت بيرفض أي طلب من غيرها.
  (لو غيرته يومًا: غيّره في CONFIG.OUTREACH_SECRET جوه السكريبت
  وفي إعدادات الصفحة.)
- الكود المدموج بيعمل تاب جديد اسمه Listings جوه الشيت — مش بيعدّل
  ولا يمسح أي تابات أو صفوف موجودة.
- أعمدة تاب Listings (١٥ عمود): Code | Compound | Bedrooms |
  Bathrooms | Area (sqm) | Price | Currency | Furnished | Owner
  Phone | WhatsApp Content | Facebook Content | Property Finder
  Content | Map Link | Images (URLs) | Created At.
- اسم الكومباوند بيتوحّد تلقائيًا بنفس قاموس الأسماء الشهيرة
  اللي في محرككم (cfc → Cairo Festival City وهكذا).
- تليفون المالك بيتخزن كنص مع الحفاظ على الصفر (01xxxxxxxxx).
- الصور بتتخزن في مجلد «Easy Listing Images» على Drive بتاع
  الحساب اللي نشر السكريبت — لينكاتها بتتفتح لأي حد معاه اللينك.
- لو ظهرلك «استجابة غير متوقعة» عند الاختبار: اتأكد إن الـ Web app
  منشور بـ Who has access: Anyone (مش Anyone with Google account).
- كود الوحدة: بادئة الكومباوند (MI = ميفيدا، MV = ماونتن فيو،
  PH = بالم هيلز...) + عدد الغرف مع F (مفروش) / U (غير مفروش) +
  السعر (10M / 950K). لو الكود اتكرر بيضاف رقم بعده.
- الإعدادات بتتحفظ على جهاز كل موظف (localStorage) — كل واحد بيدخل
  اللينك مرة واحدة بس.
