═══════════════════════════════════════════════════════════════════
  ربط صفحة الموقع العامة بالشيت — Sierra Estates
  (sierra-estates.net/add-listing  →  Google Sheet)
═══════════════════════════════════════════════════════════════════

الفكرة في سطر واحد:
  أي مالك أو بروكر يفتح الصفحة العامة (من غير أي اكسيس) ويعبي الوحدة
  → الوحدة تنزل صف جديد في تب «Website_Listings» في الشيت
  بتاريخ الإضافة + آخر تحديث + كل المواصفات + الصور على Drive
  + لينك الموقع + لينك الخريطة + لينك الانفنتوري (لينك مباشر للصف نفسه).

كود الموقع نفسه اتظبط وخلاص — اللي عليك بس ٤ خطوات (١٠ دقايق).

───────────────────────────────────────────────────────────────────
الخطوة ١: حدّث السكربت في الشيت (٥ دقايق)
───────────────────────────────────────────────────────────────────
  ١. افتح الشيت:
     https://docs.google.com/spreadsheets/d/1g9GIcCM0slC5QplgzatZRxU46O_N4CR2jgDp9DeMYZk/edit
  ٢. Extensions ← Apps Script
  ٣. افتح ملف apps-script-easy-listing.gs المرفق (v6.1)
     ← انسخ كل الكود ← اعمل Ctrl+A في المحرر ← الصق ← احفظ (Ctrl+S)

  ⚠️ مطمّن تاني: النسخة v6.1 = نفس محركك القديم سطر بسطر
     (البوت + الماستر + الأوديت + الـ onEdit) + إضافات فوقهم بس.
     مفيش أي حاجة بتتمسح. لو عندك v6.0 متلصق قبل كده — برضه الصق
     v6.1 كله مكانها (هي نفسها + Mode D الجديد).

───────────────────────────────────────────────────────────────────
الخطوة ٢: انشر النسخة الجديدة وخد اللينك (٢ دقيقة)
───────────────────────────────────────────────────────────────────
  ١. Deploy ← Manage deployments ← ✏️ (قلم التعديل)
  ٢. Version: New version ← Deploy
     — نفس اللينك القديم بيفضل شغال → البوت والإضافة القديمة مفيش
       أي حاجة هتتقطع.
  ٣. انسخ الـ Web app URL (شكله كده):
     https://script.google.com/macros/s/AKfy.../exec
     — محتاجينه في الخطوة ٣.

───────────────────────────────────────────────────────────────────
الخطوة ٣: حط متغيرين في Vercel (٢ دقيقة)
───────────────────────────────────────────────────────────────────
  ١. افتح vercel.com واختار مشروع الموقع (sierra-estates.net)
  ٢. Settings ← Environment Variables ← Add:
       Name:  SHEETS_WEBAPP_URL
       Value: لينك الويب آب اللي نسخته (ينتهي بـ /exec)
       Environments: Production (و Preview لو تحب)
  ٣. تاني Add:
       Name:  SHEETS_WEBAPP_SECRET
       Value: SE_OUTREACH_SECRET_2026_CAIRO
       (نفس السر القديم بتاع البوت بالظبط)
  ٤. بعد الحفظ: Deployments ← أحدث دبلوية ← ⋯ ← Redeploy
     عشان المتغيرات الجديدة تشتغل.

  🔒 السر بيتحط على السيرفر بس — الزائر العادي مش شايفه ولا
     أي حد من برة، لأن اللي بيكلّم جوجل هو باك-إند الموقع مش المتصفح.

───────────────────────────────────────────────────────────────────
الخطوة ٤: اختبر من الموبايل (١ دقيقة)
───────────────────────────────────────────────────────────────────
  ١. افتح من الموبايل (مهم تكون خارج من حسابات جوجل أو من
     متصفح خاص):
     https://sierra-estates.net/add-listing
  ٢. عبي وحدة تجريبية (كومباوند + مساحة + سعر + اسمك + رقمك)
     وارفع صورة أو اتنين ← Submit listing
  ٣. افتح الشيت ← هتلاقي تب جديد اسمه Website_Listings:
     صف جديد فيه التاريخ + المواصفات + الموبايل + الصور
     (لينكات Drive) + لينك الموقع + لينك الخريطة + لينك الانفنتوري.
  ٤. لو دخلت على تلجرام/واتساب الإدارة هتلاقي إشعار الوحدة
     ومعاه «Sheet row» = لينك مباشر للصف في الشيت.

═══════════════════════════════════════════════════════════════════
إزاي بيشتغل — ملاحظات
═══════════════════════════════════════════════════════════════════
- كل حاجة كانت شغالة قبل كدهفضل شغالة زي ما هي:
  Supabase + إشعارات تلجرام/واتساب + بث جروب الملاك. الاتنين
  الجداد: مراياة الشيت (Website_Listings) + الصور على Drive.
- نفس رقم الطلب بيتحمل مرتين = تحديث لنفس الصف و«آخر تحديث»
  بيتجدد — مش تكرار.
- الكومباوند بيتوحّد تلقائي بنفس قاموس الأسماء (cfc → Cairo
  Festival City...).
- لينك الخريطة: بينقطة الكومباوند بالظبط لو معروف في القاموس،
  وإلا بحث جوجل ماب باسمه.
- لينك الموقع هيفتح صفحة الوحدة على sierra-estates.net بعد ما
  تنشرها من المراجعة (قبل النشر بيكتب Not Published Yet — عادي).
- عمود «حالة المراجعة» بيبدأ «بانتظار المراجعة» — غيّره إدريًا
  لما فريقك يخلص معاينة.
- الصور بتترفع في نفس مجلد «Easy Listing Images» على Drive.
- متغيرات Vercel مش موجودة؟ الصفحة شغالة عادي والمزامنة بتتخطى
  لوحدها (مفيش أي حاجة بتتكسر) — لحد ما تضيفها.

───────────────────────────────────────────────────────────────────
لو ظهرت مشكلة
───────────────────────────────────────────────────────────────────
- الصفحة بتبعت عادي بس مفيش صف في الشيت:
  اتأكد من متغير SHEETS_WEBAPP_URL في Vercel + إنك عملت
  Redeploy، واتأكد إن السكربت المتلصق هو v6.1 وعامل Deploy
  New version.
- «Sheet row» مش ظاهر في إشعار تلجرام:
  معناه المزامنة اتخطّت — راجع النقطتين فوق.
- استجابة غريبة من Apps Script:
  اتأكد الويب آب منشور بـ Who has access: Anyone (زي البوت).
