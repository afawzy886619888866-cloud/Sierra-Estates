# Property Finder — DRAFT feeds (NOT published, NOT publicly served)

These XML files are **drafts for operator review only**. They were moved here
from `apps/sierra-estates-realty/public/feeds/` on 2026-10-20 because files
under `public/` are served verbatim by both the static asset layer
(`/feeds/<name>.xml`) and — far worse — the pre-generated branch that used to
sit at the top of `app/api/feeds/property-finder/route.ts` served
`propertyfinder-feed.xml` (last_update 2026-10-04, ~1,762 `OWNERS-AUG26-*`
owner-scraped ads, price-on-application rows included) as the LIVE production
feed, bypassing the canonical publication gate entirely.

## Rules (mandate 2026-10-20)

1. **Nothing in this directory is ever auto-served.** The public feed is
   generated exclusively by `/api/feeds/property-finder` from canonical
   `publish_status = 'PUBLISHABLE'` rows.
2. **Provenance:** the drafts were generated by the legacy
   `scripts/publish-propertyfinder-ads.mjs` / `export-propertyfinder-feed.mjs`
   pipeline from owner-scraped sheet data — unverified by definition.
3. **Publication path:** to publish any of this inventory, first drive the
   rows through canonical verification (`draft → pending_verification →
   verified → published`), then let the gated route export them. A dossier or
   draft XML is never evidence of submission, acceptance, or publication.
4. Do not move these files back under any `public/` directory.
