# Firebase App Check archive

Check is not part of the active Sierra Estates runtime because Firebase is no
longer the canonical backend.

Use Supabase Auth, RLS, server-side service-role boundaries, webhook secrets,
and the active checks in [`SECURITY.md`](../SECURITY.md) instead.

Do not follow the Firebase console, Firestore rules, or `pnpm deploy:rules`
instructions from the superseded version of this document.
