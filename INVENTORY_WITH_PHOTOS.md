# Inventory with Photos

`Inventory_with_Photos.xlsx` is the unified Sierra Estates inventory workbook with the requested photo-ready filename. The WhatsApp archives currently available for this project contain text exports only and no image/media files, so the workbook contains no fabricated photo URLs or placeholder attachments.

When a WhatsApp export that includes its `Media` folder is supplied, the media ingestion process should match photos to `RecordID` with a confidence check, populate photo fields only for confidently matched units, and produce an Airtable view named `Units With Photos`.

The companion `Inventory_with_Photos_Airtable.csv` is the Airtable-ready export of the current 9,094 records.
